# v1.1.0 · 系统课

首个公开版本，聚焦“理解一手棋”，而不是背坐标。

## 新增

- **系统课六阶段 22 课**：眼力与规则 → 空间与开局 → 黑棋取胜 → 防守与反击 → 白棋胜法 → 学习方法。
- 新增 5 课：子力结构、空间感、真四三与反四、冲四解围、白棋抓禁手。
- 每日 15 分钟训练循环、棋感与复盘方法。
- 系统课首页显示阶段进度，可直接“继续下一课”。

## 已有

- 26 种标准前三手起形；花月、浦月、疏星、寒星、松月、山月各 3 条短分支。
- 30 个方向练习（15 个原创母题 × 2 方向），接受已验证的多个解。
- 自由摆棋、撤销/重做、旋转、连珠棋形检查。
- 课程笔记、错题复习、收藏、JSON 备份与导入前恢复副本。
- 离线 APK，无网络、账号、广告或自动云同步。

## 验证

- 16 组最终 APK 内页面 Chrome 检查通过。
- APK v2/v3 签名、4 字节对齐、无 `uses-permission` 检查通过。

## 安装

Android 7.0 / API 24 及以上，建议较新的系统 WebView / Chrome（Chromium 100+）。个人侧载，不是应用商店上架包。

从旧版覆盖安装即可，包名与签名未变；不要卸载，以免清掉本机学习记录。

## 已知边界

- 未连接安卓真机；真机触摸、系统文件选择器、返回键与生命周期尚未验证。
- 开局分支是教学示例，不是完整职业定式库或最强手排名。
- 战术题采用明确标注的无禁手规则；有禁手讲解单独标注。
- 内容经过程序与来源核对，但未经过职业棋手审稿。
- 课程文字稿来自公开视频的本机语音识别，仅供个人学习研究，**不随仓库或 APK 分发**。
