# 内容设计与规则依据

核验日期：2026-11-18。

## 教学目标

每个环节围绕“看见什么、准备怎么下、对手最强怎么应、为什么仍成立”组织，不用大量空泛口诀代替局面分析。

- 规则先在棋盘上演练，交换时持续显示“谁执黑、谁执白”。
- 活三按能否真实延伸成活四解释；禁手检查不只数外观。
- 开局比较白方限制位置、黑方连接材料和空间，逐手说明意图。
- 战术题接受满足题目目标的已验证多解，错误不被表述成全局必败。
- 提示与独立完成分开；先看解后立即重做仍计帮助，不用进度伪造棋力。
- 工字等结构从材料与次序解释，并展示少一颗支援子时原路线可能失效。
- 通过摆棋、课程笔记、错题复习和实战转折复盘完成学习循环。

## 系统课路径

系统课按六阶段组织 22 课，不是把 17 节旧课简单堆在一起：

| 阶段 | 目标 | 主要内容 |
| --- | --- | --- |
| 眼力与规则 | 先看清 | 五/四/三、真假活三、三三/四四/长连、子力结构 |
| 空间与开局 | 让材料有地方长大 | 空间感、交换与两打、开局计划 |
| 黑棋取胜 | 学会兑现 | 四三、反四、VCF、工字/三角、做杀与双杀 |
| 防守与反击 | 先守后反 | 阻断后续、反三夺先、冲四解围 |
| 白棋胜法 | 利用规则 | 双三/双四、抓三三/四四/长连 |
| 学习方法 | 把计算变成习惯 | 棋感、计算、复盘、15 分钟循环 |

路径设计参考公开课程《五子棋系统教程·基础篇》（华韬五子棋，B站 `BV1q54y1o7HQ` / `BV17F411F7LV`）的教学顺序与概念：眼力→规则→子力/空间→四三/VCF→防守→抓禁手→做杀/做VCF→综合训练。**讲解文字、题面和程序判定为本项目重写；没有复制课程棋盘图、棋谱、音频或原文讲稿，也没有把课程音频打包进 App。** 逐集自动文字稿只保存在本机 `X:\GomokuCourse`，供个人学习研究。

系统课不声称覆盖课程全部细节，也不把“做杀/VCF”写成无条件必胜；每道题仍以程序验证的路线为准，并保留“未找到不等于无解”的边界。

## 规则分层

| 场景 | 规则口径 |
| --- | --- |
| 基础、全部战术习题 | 无禁手，五连及长连胜 |
| 连珠规则讲解、候选点检查 | 黑恰好五连胜，五连优先；否则三三/四四/长连禁手；白长连胜；真假活三检查合法延伸 |
| 交换演练 | 26 起形之一 → 第二位可交换 → 白4 → 黑给两个不同形5 → 白选一个 → 白6 |
| 起形库 | 13 直指 + 13 斜指；坐标 A—O，含 I；黑1 H8 |
| 摆棋 | 编辑器，不强制比赛轮次/终局；可做有禁手的候选点辅助检查 |

关于三三的递归延伸：先检查真实四，再在能够得到两端均可成五的四的延伸点上检查黑方合法性；真实三由原三颗子的集合去重。同一活四两个端点只算一条四，同线不同四颗子集合则可以构成四四。

## 开局与短分支

- 名称、D/I 编号及前三手几何位置按中国 2025 规则附录及 RenjuNet 起形图核对。
- RenjuNet 图使用跳过 I 的列标，不能把它的 J 坐标直接抄为本 App 的 J；本项目按几何位置转换到 A—O。
- 六个入门起形各三条短分支，重点是近身限制、换方向、远离中心等计划比较；其中有明确的弱防对照。
- 分支不是职业定式、引擎最强结果或强制获胜证明，不提供伪造胜率。
- 分支里的第5手表示白方从两打中保留的实际黑5；真实候选点程序单独在规则课演练。

## 题库核验范围

题目由本项目构造，未打包第三方文章或棋谱。

- 15 个母题，各两个方向，共30个方向练习；不是30个独立新构型。
- 一步题遍历全部空点，检查是否实现成五、活四、双成五点或消除对方立即成五。
- 连续四题枚举候选起手和强制应手，在指定深度内寻找取胜证明。
- 强制冲四处独立核验其他不挡四应手会留下成五；双成五点处核验防守方没有直接成五的反击。
- 展示路线必须逐手在真实棋盘上落子，最终确实成五；防守题则只检查立即威胁被消除。
- 搜索失败没有被包装为“全局无解”或“必败”；没有把一个评分函数冒充完整博弈证明。
