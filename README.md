# 五子棋研习 · Android 1.1.0

一个离线、棋盘优先的五子棋学习 App。核心不是背坐标，而是理解落子用途、比较应手，再动手验证。

**制作 / 署名：段小段。**

- Release 资产：`五子棋研习-v1.1.0.apk`（英文同字节副本 `Gomoku-Study-v1.1.0.apk`）

## 安装与使用

- 本地构建安装包：`dist/五子棋研习-v1.1.0.apk`，英文同字节副本 `dist/Gomoku-Study-v1.1.0.apk`。
- Android 最低声明版本为 7.0 / API 24；页面使用现代 JavaScript，需较新的系统 Android System WebView / Chrome（建议 Chromium 100 或以上）。未在旧 WebView 上承诺兼容。
- 本包用于个人侧载，targetSdk 34、compileSdk 35；不是应用商店上架包，不代表符合未来商店政策。
- 不需要账号或网络。通过系统正常的“允许此来源安装应用”流程安装，不需关闭系统安全防护。
- 进入后是“系统课”路线。底部四个入口：**系统、开局、练习、摆棋**；右上角是学习记录、字号、主题、备份和关于。

## 先讲清内容边界

1. 正确术语是 **三手交换、五手两打**。演练交换的是棋手执色，不是改变盘上棋子颜色；黑5候选最终只留一个，之后白方下白6。
2. 2025 年中国竞赛规则还列有塔拉山口-10 等开局。五手两打不是所有比赛唯一的模式。
3. 练题全部明确采用无禁手规则。黑双三、双四不能直接照搬到有禁手连珠比赛。
4. 开局短分支是棋理示例，包含近防、换方向与不充分防守的对照；不是最强手排名、职业定式库或胜率结论。
5. 工字、T 型、三角等名称用于发现连接材料，不是“只要像这个字就必胜”。工字课及习题使用本项目原创简化构型。
6. 连续四搜索只证明指定深度内存在可兑现路线；未找到不代表没有 VCT 或其他更长取胜路线。防守题仅要求消除立即成五，不承诺守和。
7. 棋形检查不处理比赛计时、pass、违规申诉、双方确认胜负等裁判流程。摆棋本身允许自由构型，不强制完整对局的可达性。
8. 内容有程序核验及来源核对，但未经过职业棋手审稿；不应作为裁判资格教材。
9. 系统课的学习顺序参考公开课程《五子棋系统教程·基础篇》（华韬五子棋）的教学结构；讲解、题面和判定为本项目重写，未打包课程音频、画面、棋盘图或原文讲稿。逐集文字稿另存在 `X:\GomokuCourse`，仅供个人学习研究，不随 App 分发。

来源和口径见 `docs/内容与规则.md`；App 关于页也保留来源。

## 保存、导出与隐私

- 独立包名：`com.duan.gomokustudy`。
- 网页虚拟来源：`https://app.local/`，只是本地内容来源，不是网络网站。
- 主记录键：`duan.gomoku-study.v1`，schema 1。导入前副本键加 `.before-import`。
- 数据在 Android 本应用的 WebView 本地存储中；不使用旧 App 的包名、存储键或记录。卸载、清理应用数据会丢失，移动 APK 文件不影响已安装的记录。
- 笔记、课程进度、题目记录、设置和当前摆棋自动保存。开局演练的临时步骤、解题路线播放位置和摆棋撤销栈只保留本次运行，不承诺重启续播。
- 手动导入**替换**当前记录，不是合并；先完整校验，再保存旧原文为恢复副本。坏数据读取失败时暂停自动写入，不静默清空覆盖。
- 原生只暴露主题和用户发起的 JSON 导入/导出窄接口；通过系统文档选择器访问用户指定文件，没有通用文件读取或执行桥。
- APK 未声明网络或广泛存储权限；内容、字体使用本地资源或系统字体，无第三方运行时 JS 依赖。用户若自行选择云盘文档提供器，由该提供器处理文件，不等于本 App 自动上传。

## 源码入口与本机构建

| 路径 | 职责 |
| --- | --- |
| `web/core.js` | 棋盘、坐标、旋转镜像、连五、真实四/三、黑棋禁手、有限连续四证明 |
| `web/content.js` | 课程、起形、短分支、规则来源 |
| `tools/generate-puzzles.cjs` | 原创题型构造，计算并生成所有已核验起手与路线 |
| `web/puzzles.js` | 生成的离线题库，不手工修改 |
| `web/storage.js` | schema、输入校验、保存及导入前保护 |
| `web/app.js` / `styles.css` | 交互与布局 |
| `app/src/main/` | Android manifest、原生 WebView、主题与文档选择器 |
| `tools/` | 单元、内容、存储、界面与最终 APK 检查 |

优先复用本机已有工具，没有新增工具或其他模型调用。SDK、JDK、缓存与构建暂存均在 X 盘。

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build-apk.ps1
& 'B:\Python310\python.exe' .\tools\verify-apk.py
node .\tools\ui.test.cjs .\qa\extracted\app.html
```

- Android SDK：`X:\OpenCodeTools\android-sdk`；JDK 17、Build Tools 35.0.0、android-35。
- UI 测试：系统 Chrome + 已有 `X:\OpenCodeTools\temp\ms-test\node_modules\puppeteer-core`，无新浏览器下载。该依赖位于既有临时工具目录，迁移电脑时需重新确认路径。
- `build-apk.ps1 -Smoke` 仅用于最小打包链路，输出到 `qa/minimal/`，不是最终包验收，也不跳过正式发版检查。
- 单独逻辑测试：`node --test tools/core.test.cjs tools/content.test.cjs tools/storage.test.cjs`。
- 构建脚本会先重新生成题库，再执行测试。`aapt2 → javac → D8 → zipalign → apksigner` 在 X 盘英文暂存目录执行，避免中文路径问题。
